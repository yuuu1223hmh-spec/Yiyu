開啟英文論文或網頁文章，點一下句子就有中文翻譯，點單字看釋義。

最近開啟

還沒有開過文件。也可以先。
設定

API 金鑰

到 platform.claude.com 的 API Keys 頁面建立。金鑰只存在這台裝置上，只會傳給 Anthropic。

翻譯模型

網址讀取方式

使用公開服務時，你貼的網址會經過該服務。需要登入才能看的付費全文無法讀取。

個人字典與資料

字典已收錄 0 個字。查過的字存在這台裝置上，再遇到時直接顯示，不耗用額度。

怎麼用

點一下句子：浮窗翻譯整段，並標出段落範圍。
浮窗裡點「查某某字」：看單字釋義。
拖曳或長按選取文字：按「翻譯選取」只翻那部分。

貼上英文文章

網頁、新聞或期刊的內容都可以。段落之間空一行效果最好。

從網址匯入

貼上文章網址，譯讀會抓下內文讓你點選翻譯。
