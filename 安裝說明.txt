譯讀 · 安裝說明
================

整體流程：把這個資料夾放上免費網站（GitHub Pages）→ 在 Windows 和 iPad 打開網址並安裝 → 貼上 API 金鑰。
只有第一次需要做，大約 20 分鐘。


一、放上網站（只做一次，用 Windows 電腦做比較方便）
------------------------------------------------
1. 到 https://github.com 註冊免費帳號。帳號名稱會出現在你的 App 網址裡。
2. 登入後，按右上角「+」→「New repository」。
   - Repository name：輸入 yidu
   - 選「Public」（免費方案的網站空間需要公開；裡面只有程式，沒有你的任何資料）
   - 勾選「Add a README file」
   - 按「Create repository」
3. 進入剛建立的 yidu，按「Add file」→「Upload files」。
   把這個資料夾「裡面的所有檔案」一起拖進去（不是拖整個資料夾），
   等全部上傳完，按下方綠色的「Commit changes」。
4. 按上方的「Settings」→ 左側「Pages」。
   在「Build and deployment」：Source 選「Deploy from a branch」，Branch 選「main」、資料夾選「/ (root)」，按「Save」。
5. 等 1～2 分鐘後重新整理這頁，上方會出現你的網址：
   https://你的帳號.github.io/yidu/


二、安裝成 App
--------------
Windows（Edge 或 Chrome）
1. 打開上面的網址。
2. 網址列右邊會出現「安裝」圖示，按下去。沒看到的話，到瀏覽器右上角選單找「應用程式」或「投放、儲存與分享」裡的「安裝」。
3. 裝好後，開始選單和桌面會有「譯讀」圖示，會用獨立視窗開啟。
4. 之後在檔案總管對 PDF 按右鍵 →「開啟檔案」→ 選譯讀，也能直接打開。

iPad
1. 用 Safari 打開同一個網址（一定要用 Safari）。
2. 按網址列旁的「分享」圖示 →「加入主畫面」→「加入」。
3. 主畫面會出現「譯讀」圖示，點開就是全螢幕 App。


三、設定 API 金鑰（每台裝置各設定一次）
----------------------------------------
1. 到 https://platform.claude.com 註冊或登入。
2. 在 Billing（帳單）頁面購買點數。第一次買小額即可，照一般用量一年都用不完。
   點數購買後一年到期、不能退款。
   如果你的 Claude 訂閱是 Max、Ultra 或 Team 方案，可以在 claude.ai 的「設定 → 帳單」領取每月附贈的 API 點數，不用另外付費。
3. 到「API Keys」→「Create Key」，複製以 sk-ant- 開頭的金鑰（只會顯示一次，可以先存在密碼管理工具）。
4. 打開譯讀 → 右上角「設定」→ 貼上金鑰 → 按「儲存並測試」，看到「連線成功」就完成了。

注意：金鑰、個人字典、翻譯紀錄都只存在各自的裝置上，Windows 和 iPad 不會互通，兩邊都要各貼一次金鑰。
請不要把金鑰傳給別人或貼到網路上；萬一外流，到 platform.claude.com 刪除那把金鑰再建一把新的。


四、怎麼用
----------
- 開啟：PDF（保留原版面）、Word（.docx）、純文字檔
- 網址：貼上文章網址，自動抓內文
- 點一下句子：浮窗翻譯整段，並標出段落範圍
- 浮窗裡按「查某某字」：看單字釋義；查過的字會存進個人字典，之後不耗額度
- 拖曳或長按選取文字：按「翻譯選取」只翻那部分
- 摘要：整理研究問題、方法、發現和關鍵術語
- 首頁會保留最近開過的 12 份文件


五、（選用）自己的網址中繼
--------------------------
預設的網址匯入會經過公開服務 r.jina.ai。想更私密，或想直接讀 PDF 網址，可以架自己的中繼：
1. 到 https://dash.cloudflare.com 註冊免費帳號。
2. 左側「Workers & Pages」→「Create」→ 建立一個 Worker（用預設的 Hello World 範本）→「Deploy」。
3. 按「Edit code」，把 cloudflare-worker.js 的內容整個貼上取代原本的程式 →「Deploy」。
4. 複製這個 Worker 的網址（結尾是 workers.dev）。
5. 譯讀 →「設定」→「網址讀取方式」選「我自己的 Cloudflare 中繼」，貼上網址。

不論哪種方式，需要登入學校帳號才能看的付費全文都抓不到，請下載 PDF 再用「開啟」。


六、之後要更新 App
------------------
我改好新版本後，把新的檔案用同樣方法「Upload files」上傳到 yidu（會覆蓋舊檔）。
裝好的 App 下次開啟時會自動換成新版；如果沒更新，關掉 App 重開一次。
